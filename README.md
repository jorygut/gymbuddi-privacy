# GymBuddi Privacy Policy

The privacy policy for the GymBuddi iOS app, published via GitHub Pages.

Live at: https://jorygut.github.io/gymbuddi-privacy/

GymBuddi collects no data. Workout data stays on the user's device and, when
iCloud is enabled, syncs to their own private CloudKit database, which the
developer cannot access.
